B · apiCall() — le pont PHP→données (249-361)

Cette fonction est le cœur du rendu serveur. Elle appelle un endpoint /api/*.php mais court-circuite par une lecture directe du fichier cache local quand il existe (pour stats, epreuve_stats, athlete, club_stats). Elle renvoie le tableau PHP décodé.

ℹ️
C'est apiCall() qui fait l'« appel loopback » : en prod, sans les cookies du visiteur.

E · Les DEUX profils (piège important)

⚠️ Il existe deux versions de la fiche athlète
  • ?page=profil (lignes 5769-9462) = profil v1 « magazine » : la vue publique actuelle, narrative et stylée (citation, hall of fame, « saviez-vous », progression, athlètes similaires, graphiques Chart.js). Inclut profile_gate.php (1 fiche/jour gratuite + cooldown).
  • ?page=profil2 (lignes 4393-5768) = profil v2 : vue détaillée à onglets (données brutes). Les anciennes URLs profil2 sont redirigées vers profil.
Les deux respectent visible (profil masqué) et incrémentent les vues. Quand tu modifies « le profil », vérifie de quelle version il s'agit.
