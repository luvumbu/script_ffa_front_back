04. BACKEND — Authentification

Connexion via Google OAuth uniquement

Plus de formulaire email+mdp pour les utilisateurs. Bouton Se connecter avec Google sur login.php et register.php.

Flux Google OAuth 2.0

login.php
   │ clic "Se connecter avec Google"
   ▼
api/auth/google_login.php
   │ genere state CSRF en session
   │ redirect Google avec client_id + state
   ▼
Google (consentement)
   │ redirect vers callback avec code + state
   ▼
api/auth/google_callback.php
   │ verifie state CSRF
   │ echange code → access_token (POST cote serveur)
   │ recupere profil (email, nom, google_id)
   │ si email existe : lie google_id au compte
   │ sinon : cree user (role=athlete, oauth_provider=google)
   │ createSession() → cookie bk_token (30j)
   ▼
index.php (connecte)

Sessions

  • Token : 64 chars hex via bin2hex(random_bytes(32))
  • Cookie : bk_token (httpOnly, sameSite=Lax, TTL 30j)
  • Stockage : table user_sessions
  • Validation : getCurrentUser() dans core/auth.php

Roles

athlete (defaut) coach club admin

Verification : requireAuth(), requireRole('admin')

Super Admin (separe)

  • Login via login.php en utilisant credentials BDD
  • Detection : api/auth/login.php compare avec core/credentials.php
  • Cookie : bk_sa_token (7 jours)
  • Stockage : logs/.sa_sessions.php (JSON proteges die())
  • Acces : admin/panel.php (16 sections)
  • Rate limit : 5 tentatives/jour par IP, blocage 24h

Convertit perf texte en centiemes (temps) ou centimetres (distances). 7 patterns testes dans l'ordre :

ATTENTION — Padding dixiemes

Quand 1 seul chiffre apres '', m, ou ., c'est un dixieme. str_pad($digit, 2, '0', STR_PAD_RIGHT) : '9' → '90'.

Sans padding (BUG) : 10''9 → 1009 (10.09s, faux)
Avec padding (CORRECT) : 10''9 → 1090 (10.9s)

Script de correction BDD : admin/fix_perf_int.php (dry run sans param, ?go execute correction SQL : FLOOR(perf/100)*100 + MOD(perf,100)*10).

Workflow par cycle (25s max)

  1. Charge URLs depuis nom_et_liens → cache urls_cache.json
  2. Charge tous les athlete_id_externe deja en BDD → $existingAthletes[] (skip)
  3. Boucle batch : collecte 7 athletes non-existants
  4. scrapeParallel() → telecharge 21 pages parallel
  5. Pour chaque : AthleteScraper → extraction → JSON src/{id}.php → BDD
  6. Echecs → failed.json
  7. Progression → progress.txt + session
  8. Verifie flag → reload ou stop
